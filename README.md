# Controle-Meteorolgico

# 🚀 - Bootcamp Generation Brasil

> Projeto desenvolvido durante as aulas práticas do bootcamp da **Generation Brasil**, aplicando conceitos fundamentais de consumo de **APIs**, manipulação avançada de **Listas (Arrays)** e estruturas chave-valor (**Dicionários/Objetos JSON**).

---

## 📸 Demonstração Visual

Uma interface limpa, responsiva e moderna (*Glassmorphism* / Design System minimalista) desenvolvida com foco em UX/UI para exibição e filtro dinâmico de dados.

---

## 🎯 Objetivos Pedagógicos & Técnicos

Este projeto foi construído para consolidar os seguintes aprendizados do bootcamp:
1. **Consumo e Simulação de API:** Compreensão do ciclo de requisições assíncronas (`async/await`, promessas e tratamento de latência).
2. **Manipulação de Listas:** Uso intensivo de métodos nativos de arrays do JavaScript (`.filter()`, `.forEach()`, `.map()`).
3. **Tratamento de Dicionários / JSON:** Extração e navegação por propriedades aninhadas em objetos (estruturas chave-valor).
4. **Clean Code & Vanilla Front-End:** HTML5 semântico, CSS3 moderno com variáveis customizadas e JavaScript modularizado em um único arquivo de alta performance.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização moderna com Flexbox, Variáveis CSS e Design Responsivo.
* **JavaScript (ES6+):** Funções assíncronas, arrow functions e manipulação do DOM em tempo real.
* **GitHub Pages:** Hospedagem contínua e gratuita.
